The idea概念

A token is a keyToken 就是一把鑰匙

1

Your Facebook login你的 Facebook 帳號

It proves you manage the accounts.

證明你有這些帳號的管理權限。

2

Your app你的 App

A container Meta asks you to create.

Meta 要求建立的一個容器。

3

The tokenToken

A long code, saved in a file on your PC.

一長串代碼，存在自己電腦的檔案裡。

4

Claude Code

Uses the token to read Instagram and ad numbers.

用 Token 讀取 Instagram 與廣告數據。

Your password is never shared. Keep the token private, like a password.

不需要提供密碼。Token 請像密碼一樣保管。

Three things to check先確認三件事

✓

Instagram is a professional account, linked to a Facebook PageInstagram 是專業帳號，並已連結 Facebook 粉絲專頁

Business or Creator both work.

商業帳號或創作者帳號皆可。

第一次使用：點 Get Started 完成註冊。

Step 1 of 6步驟 1

Create an app建立 App

developers.facebook.com → My Apps → Create App

  1. Name it, for example MKT Report TW.

    取一個名稱，例如 MKT Report TW。

  2. Use case: Other. App type: Business.

    使用案例選 Other，類型選 Business。

  3. Connect your business portfolio, then click Go to dashboard.

    連結你們的企業管理平台，再點 Go to dashboard。

Leave the app in Development mode. It only reads your own accounts, so it needs no app review.

App 保持 Development 模式即可。它只讀取你們自己的帳號，不需要送審。

Step 2 of 6步驟 2

Generate a token產生 Token

developers.facebook.com → Tools → Graph API Explorer

  1. Meta App: choose your app.

    在 Meta App 選擇你的 App。

  2. User or Page: choose Get User Access Token.

    在 User or Page 選 Get User Access Token。

  3. Add the six permissions.

    加入六個權限。

  4. Click Generate Access Token. In the pop-up, select your Instagram account, Page and business.

    點 Generate Access Token。在彈出視窗中選取 Instagram 帳號、粉絲專頁與企業管理平台。

Step 3 of 6步驟 3

Make it last 60 days延長為 60 天

developers.facebook.com → Tools → Access Token Debugger

  1. Paste the token and click Debug.

    貼上 Token，點 Debug。

  2. Scroll to the bottom and click Extend Access Token.

    捲到最下方，點 Extend Access Token。

  3. Copy the new token.

    複製新的 Token。

Skip this step and the token stops working after about an hour.

如果跳過這一步，Token 大約一小時後就會失效。

Step 4 of 6步驟 4

Save it on your PC存在自己的電腦

Notepad → meta_token.txt

  1. Paste the new token into Notepad.

    把新的 Token 貼到記事本。

  2. Save it as meta_token.txt.

    存成 meta_token.txt。

  3. Keep it in a private folder, for example C:\Users\you\.mkt\.

Four common problems四個常見問題

You see現象
Do this處理方式

Claude finds no Instagram account

Claude 找不到 Instagram 帳號

Link Instagram to a Page in Instagram settings. Then redo step 2 and select it in the pop-up.

先在 Instagram 設定中連結粉絲專頁，再重做步驟 2，並在彈出視窗中選取。

A permission error

出現權限錯誤

Add all six permissions and redo step 2. If it still fails, ask your Business admin for access.

六個權限都加上後重做步驟 2。如果還是不行，請企業管理平台管理員開權限。

“Session has expired” or “invalid token”

顯示工作階段已過期或 Token 無效

The token was not extended, or 60 days have passed. Redo steps 2 to 4.

Token 沒有延長，或已超過 60 天。重做步驟 2 到 4。

No Extend Access Token button

找不到 Extend Access Token 按鈕

Ask Claude to extend the token. It needs the App ID and App Secret from App settings → Basic. Save them in a file on your PC and never paste them into the chat.

請 Claude 幫忙延長 Token。它需要 App settings → Basic 裡的 App ID 與 App Secret。請存成自己電腦上的檔案，不要貼進對話。

Button names are given in English. If your developer site is in Chinese, the buttons sit in the same places.

按鈕名稱以英文介面為準。如果你的開發者網站是中文介面，按鈕位置相同。
